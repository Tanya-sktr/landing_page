# MyBike — Bicycle Landing Page

A responsive bicycle landing page built from a Figma design.
The website showcases three bike models, their prices and key features,
and provides a contact form and contact information.

## Live Preview

[View MyBike](https://tanya-sktr.github.io/landing_page/)

## Design Reference

[Figma design](https://www.figma.com/file/NZQAIydtHo5QkINyGLHNcq/BIKE-New-Version?node-id=0%3A1)

## Technologies Used

### Core

- **HTML5** — Semantic page structure.
- **SCSS** — Styling with variables, mixins, and nesting.
- **CSS Grid & Flexbox** — Responsive layouts and element positioning.
- **BEM** — Consistent CSS class naming.

### Development & Deployment

- **Parcel** — Development server and production builds.
- **ESLint** — JavaScript linting.
- **Stylelint** — Stylesheet linting.
- **GitHub Pages** — Website hosting.

## Getting Started

1. Clone the repository: `git clone https://github.com/Tanya-sktr/landing_page.git`
2. Open the project folder: `cd landing_page`
3. Install dependencies: `npm install`
4. Start the development server: `npm start`

## Available Commands

- `npm start` — Start the development server.
- `npm run build` — Create a production build.
- `npm run lint` — Check code style.

## Features

- **Responsive Layout:** Layouts for mobile, tablet, and desktop screens.
- **Navigation Menu:** A slide-in menu with links to page sections.
- **Smooth Scrolling:** Smooth navigation between sections.
- **Bike Models:** Three bicycle models with images, descriptions, and prices.
- **Bike Details:** Illustrated sections highlighting Auto Unlock, integrated lights, brakes, and lightweight construction.
- **Hover Effects:** Visual feedback on links, buttons, and images.
- **Contact Form:** Fields for a name, email address, and message.
- **Contact Links:** Phone and email links, plus an address linked to Google Maps.
