# MyBike Landing Page

A landing page for MyBike, created to showcase modern urban bikes, their features, and contact information.

## Project Description

The MyBike Landing Page is a single-page website designed to present information about MyBike products and their key features.

It includes sections about the brand, bike models, product details, and contact information. The page is designed to be responsive, visually appealing, and easy to use across different screen sizes.

## Technical Requirements

To run this project, you will need:

- **Node.js:** A JavaScript runtime used to run the development environment.
- **NPM:** The Node.js package manager used for managing project dependencies.

## Installation and Setup

To install the project and run it locally, follow these steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Tanya-sktr/landing_page.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd landing_page
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the local development server:**

   ```bash
   npm start
   ```

## Usage

After starting the project, it will be available at:

`http://localhost:1234`

You can use this URL to preview the landing page and ensure it displays correctly. You can also make changes to the project files and see updates in real time.

## Features

- **Responsive Design:** The page is designed to work correctly on mobile, tablet, and desktop devices.
- **Interactive Elements:** Includes hover effects, navigation interactions, and a responsive menu.
- **Bike Comparison:** Displays different bike models with descriptions and prices.
- **Product Details:** Includes sections describing important bike features.
- **Contact Form:** Allows users to enter their name, email, and message.
- **Phone Hover Effect:** Displays the phone number when hovering over the phone icon on larger screens.
- **Modern Aesthetics:** Uses modern layout techniques, animations, and responsive design practices.
